Mitra: The AI Agent Party

A multi-agent collective intelligence system designed to facilitate collaborative problem-solving through specialized AI personas.

View on GitHub

Overview

Mitra defines the "Party Protocol" where agents like the Architect, Engineer, Designer, and Manager collaborate to produce comprehensive technical specifications and direct codebase implementations.

Tools and IDE Compatibility

Mitra agents are designed to be platform-agnostic. You can run them using:

  • Gemini CLI
  • Google AntiGravity
  • Claude Code

How to use

# Clone repository
git clone https://github.com/saeed-vayghan/mitra.git
cd mitra

# Config the project
nano mitra/config.yaml

# Run Gemini CLI
gemini

> /mitra:persona:orchestrator

Inspiration & Philosophy

Mitra was built with love, drawing massive inspiration from BMAD-METHOD, GitHub Spec Kit, and Fission-AI OpenSpec. While there are many incredible tools for coding, Mitra fulfills the need for a Scalable AI Implementation Framework.

  • Customizable: Easy to extend with new agents.
  • Full-Lifecycle: Covering the entire journey from Architecture and Requirements to direct implementation and testing.

Comparison with Similar Tools

Mitra stands out by providing an Implementation-First experience, where AI Agents partner with you from high-level strategy to direct source code execution.

Feature Mitra OpenSpec
Core Philosophy Implementation-First: "We Plan, We Build." Spec-Driven (SDD): "Align before you build."
Agent Role Full-Lifecycle: Planning + Direct Development. Workflow Guides: Agnostic agents guided by AGENTS.md.
Workflow Party Mode: Collaborative brainstorming + specialized routing. Proposal-Based: Draft -> Review -> Merge Specs.

Why Mitra?

Choose Mitra if you want the intelligence of a Principal Architect and Manager combined with the execution power of a Senior Engineer. It is designed to augment your workflow by handling both the thinking and the doing, providing a cohesive bridge between strategy and production code.
